# Random Color Generator

Generate a random hex color, preview it, and copy its value.

![Generated color](Generating.png)
![Copy confirmation](Copied_message.png)

## Try it

1. Open [`index.html`](index.html).
2. Select **Generate** to create a new color.
3. Select **Copy** to copy the hex value to your clipboard.

Built with HTML, CSS, JavaScript, and the browser Clipboard API.
