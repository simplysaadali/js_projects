# ⏱️ Stopwatch

A simple, interactive, and responsive **Stopwatch Web Application** built using **HTML, CSS, and JavaScript**.

The project demonstrates how JavaScript can be used to manage time, handle user interactions, update the DOM dynamically, and build an interactive browser-based application.

🔗 **Repository:** https://github.com/Atibayounus/Stop-watch.git

---

## 📌 About the Project

**Stopwatch** is a lightweight web application that allows users to accurately track elapsed time directly in the browser.

The project was created as a practical exercise to strengthen JavaScript fundamentals and understand how timing functions work together with DOM manipulation and event handling.

---

## ✨ Features

* ▶️ Start the stopwatch
* ⏸️ Pause the stopwatch

* ⏱️ Track elapsed time
* ⚡ Real-time display updates
* 🖱️ Interactive buttons
* 📱 Responsive interface

* 🌐 Runs directly in the browser

## 🧠 How It Works

The stopwatch follows a simple flow:

```text id="n9n8qg"
Start
  ↓
Timer Begins
  ↓
Update Display
  ↓
Continue Counting
  ↓
Pause / Reset
```

JavaScript repeatedly updates the displayed time while the stopwatch is running.

---

## ⏱️ Timer Logic

The application uses JavaScript timing functionality to update the stopwatch.

Common timing methods include:

```javascript id="9x5z8m"
setInterval()
```

and:

```javascript id="w2k1cd"
clearInterval()
```

`setInterval()` can repeatedly execute a function at a specified interval, while `clearInterval()` stops that repeated execution.
