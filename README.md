# JavaScript Projects Collection

A small set of beginner-friendly frontend projects built with plain HTML, CSS, and JavaScript.

## Included projects

- QR Code Generator
- Random Color Generator
- BMI Calculator
- Arithmetic Calculator
- Image Gallery
- Color Flipper

## Run locally

From this folder, start a local server:

```bash
python3 -m http.server
```

Then open `http://localhost:8000` in the browser and choose a project.
